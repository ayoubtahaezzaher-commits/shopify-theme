## Customization Options

### Theme Settings (settings_schema.json)
The merged settings schema contains entries from both themes:
- **Merrachi settings** (28 groups): Typography, colors, product cards, cart behavior, collection display, search, header/footer options, popups, wishlist, compare, recently viewed, currency, language, scroll animation, and more.
- **Ritual settings** (17 additional non-conflicting groups): Spacing, borders, grid density, color schemes, media appearances, and Ritual-specific layout options.

### Color Customization
- Merrachi uses CSS custom properties defined in `assets/base.css` and `assets/global-style.css`.
- Ritual uses `assets/ritual-base.css` and `snippets/color-schemes.liquid` / `snippets/theme-styles-variables.liquid`.

### Typography
- Merrachi: Font settings via `settings_schema.json` typography groups.
- Ritual: `snippets/fonts.liquid`, `snippets/typography-style.liquid`.

### Layout & Spacing
- Ritual's spacing system: `snippets/spacing-style.liquid`, `snippets/spacing-padding.liquid`, `snippets/gap-style.liquid`.
- Ritual's size system: `snippets/size-style.liquid`.

## Usage Examples

### Example 1: Use a Ritual Hero on a Merrachi-based Homepage

In `templates/index.json`:
```json
{
  "sections": {
    "hero": {
      "type": "hero",
      "blocks": {
        "heading": { "type": "_heading", "settings": { "heading": "Welcome" } }
      },
      "block_order": ["heading"],
      "settings": { "height": "large" }
    },
    "featured-collection": {
      "type": "featured-collection",
      "settings": { "title": "Shop Now" }
    }
  },
  "order": ["hero", "featured-collection"]
}
```

### Example 2: Use a Ritual Marquee alongside Merrachi Content

In any `.json` template:
```json
{
  "sections": {
    "announcement": {
      "type": "announcement-bar",
      "settings": {}
    },
    "ritual-ticker": {
      "type": "ritual-marquee",
      "settings": { "speed": 30 }
    }
  },
  "order": ["announcement", "ritual-ticker"]
}
```

### Example 3: Switch Specific Pages to Ritual Layout

Create a product template `templates/product.ritual-style.json`:
```json
{
  "layout": "theme-ritual",
  "sections": {
    "main": {
      "type": "product-information",
      "settings": {}
    }
  },
  "order": ["main"]
}
```
Then assign this template to products in Shopify Admin.

### Example 4: Use Ritual Price Snippet

In any Liquid file, include Ritual's price snippet:
```liquid
{% render 'ritual-price', product: product %}
```

### Example 5: Merrachi Product Card with Quick View

```liquid
{% render 'product-card',
   product: product,
   show_quick_view: true,
   show_compare: true,
   show_wishlist: true
%}
```
